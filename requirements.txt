# PyRIT et garak etaient absents de ce fichier : ils avaient ete installes par
# `pip install` direct pendant le developpement. Consequence CONSTATEE en
# lancant un audit dans l'image : « No module named 'pyrit' », la couche
# comportementale entiere echoue et l'agent ressort `not_measured`.
#
# Ce sont pourtant les deux axes qui ont detecte un detournement la ou DeepTeam
# rendait 10/10. Une image sans eux est un auditeur degrade qui ne le dit pas.
#
# LES DEUX NE SE TRAITENT PAS PAREIL, ET LE FICHIER SE CONTREDISAIT :
# `garak` etait declare ICI (actif) et re-declare 10 lignes plus bas comme
# « volontairement commente ». La premiere ligne gagnait : `pip install -r`
# tentait bel et bien l'installation, donc le build Rust que le bloc suivant
# dit d'eviter. Une seule declaration desormais, celle du bas, commentee.
pyrit

# --- Contrainte assumée, avec sa CVE connue -------------------------------
# click est épinglé à 8.1.8 (doc. technique : socle reutilisable) : les versions >= 8.4 cassent
# deepeval et semgrep, qui sont deux axes de mesure du framework.
#
# ⚠️ CVE-2026-7246 touche cette version ; corrigée en 8.3.3, hors de portée du
# pin. C'est un compromis DÉLIBÉRÉ : sans le pin, deux couches d'audit ne
# tournent plus. Impact réel faible — click ne traite ici que des arguments de
# ligne de commande fournis par l'opérateur, jamais une entrée distante.
# À lever dès que deepeval/semgrep supportent click >= 8.3.3.
click==8.1.8
